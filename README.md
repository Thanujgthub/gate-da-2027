# GATE DA 2027 preparation desk

A self-contained evidence-based preparation dashboard. Open index.html or serve this directory with any static server. Deploy on Vercel with framework preset Other; no build is required.

195 questions, 39 chapters and 103 observed subtopic families from the official 2024–2026 papers. Historical allocations are not forecasts. Verification date: 9 October 2026.

Light/dark preferences and chapter completion are saved separately in browser storage. Use the progress backup/import controls when moving between localhost and the deployed website; browser storage does not automatically transfer across origins.

No dependencies, analytics, credentials or remote assets are required. Source links require internet. Original classifications and calculations are embedded in index.html.
